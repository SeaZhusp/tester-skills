# tester-skills

一个测试工程师技能共享社区项目。收集、整理、共享 AI IDE 测试相关技能，支持团队协作和开源共建。

## 支持的平台

CodeBuddy、Cursor、Claude Code、Trae 等主流 AI IDE

## 项目结构

```
tester-skills/
├── skills/                    # 技能目录
│   ├── testcase-generator/    # 测试用例生成
│   ├── testcase-review/       # 测试用例评审
│   ├── docx/                  # Word 文档处理
│   ├── pdf/                   # PDF 文档处理
│   ├── xlsx/                  # Excel 电子表格处理
│   ├── prd-review/            # PRD 评审
│   └── fireworks-tech-graph/  # 技术图表生成
├── README.md
├── .gitignore
└── LICENSE
```

## 已有技能

| 技能名称 | 说明 |
|----------|------|
| testcase-generator | 根据 PRD 文档自动生成功能测试用例 |
| testcase-review | 对比测试用例与需求文档，找出缺失 |
| docx | 创建、编辑和分析 Word 文档（含目录、表格、修订跟踪、评论等） |
| pdf | PDF 文档处理（读取、合并、表单填写、OCR、水印、加密等） |
| xlsx | 创建、编辑和分析 Excel 电子表格（公式、图表、数据清洗等） |
| prd-review | PRD 需求文档评审，从边界条件、状态一致性、歧义假设等多维度审查 |
| fireworks-tech-graph | 生成 SVG+PNG 技术图表（架构图、流程图、时序图、UML 等 14 种类型） |
