# 测试服务套件（qa-suite）

本仓库是一个**测试服务交付套件**：1 个总控 + 4 个子技能 + 8 份共享权威规则 + 4 个脚本（3 个交付门禁 + 1 个周期换算）。

## 入口

**以 `SKILL.md` 为唯一权威入口**，请完整读取后再执行任务。

```
读 SKILL.md → 确认四道锁 → 按路由表读取 subskills/<name>/SKILL.md → 按强制读取清单读取 references/
```

## 硬性要求

1. 任何"售前评估用例数"的任务，**必须先产出 Spec Model**，再用 `scripts/count_cases.py` 模拟计数。禁止凭经验直接给条数。
2. 任何"生成用例"的任务，**必须遵守 `references/02-case-granularity-contract.md` 的计量单位**。
3. 交付前必须跑通 `scripts/` 下的三个机检脚本。
4. 产出开头必须附「激活回执头」（格式见 `SKILL.md` 第 5.1 节）。

## 目录

| 路径 | 内容 |
| --- | --- |
| `SKILL.md` | 总控（唯一入口） |
| `references/` | 共享权威规则（唯一真相，子技能只读） |
| `subskills/` | 4 个子技能 |
| `scripts/` | 机检脚本（仅依赖 Python 3 标准库） |
| `assets/` | 配置与样例数据 |

本套件不依赖任何平台的自动技能发现机制，**整体拷贝到任意位置即可使用**。
