# 微信公众号文章深度伪原创改写技能

> 核心定位：把任何文章改写成像朋友聊天一样的公众号爆款内容，原作者完全看不出痕迹
> 核心理念：**不是洗稿，是深度重写——打散全部重来**

---

## ⚠️ 硬性红线（不可违反）

1. **零AI味铁律** - 全文读起来必须像真人聊天，禁用所有AI高频词汇和句式
2. **原创度铁律** - 信息点不变但表达方式100%不同，原作者看不出照搬痕迹
3. **聊天风格铁律** - 像跟测试同事/开发朋友喝酒聊天一样，口语化、有态度、有情绪
4. **推流适配铁律** - 标题前8字含核心词、完读率驱动节奏、社交裂变埋点
5. **内容修改铁律** - 结构打散重组、案例替换、视角转换、信息增量，至少使用5种以上改写手法
6. **输出规范** - 只输出正文主体，不额外添加参考资料、附录等冗余章节
7. **链接纯文本** - ✅ `官网：url` ❌ `[官网](url)`

---

## 核心工作流（5步）

```
① 输入解析 → ② 爆款标题 → ③ 结构重组 → ④ 深度改写 → ⑤ 封面生成
```

---

## 第一步：输入解析

### 输入方式
- **方式A**：用户粘贴原始文章URL → 使用 `WebFetch` 抓取内容
- **方式B**：用户直接粘贴原文文本 → 直接进入分析
- **方式C**：用户给定主题+补充材料 → 综合整理

### 分析任务
对原文完成以下分析后再改写：
1. **提取核心信息点**（罗列出所有关键事实、数据、观点）
2. **识别原文结构**（总分总/递进式/对比式/平铺直叙）
3. **判断原文风格**（正式/口语/教程/评测/观点）
4. **标记AI味特征**（如有：完美结构、模板过渡词、空洞总结）

分析完成后向用户展示分析结果，确认信息点是否遗漏，然后再改写。

## 第二步：爆款标题生成

### 角色
公众号爆款标题专家 + 增长黑客

### 硬性要求
- 至少生成 **5个** 高点击率标题，覆盖不同类型
- 前8个字必须包含核心关键词（算法权重70%）
- 必须有冲突感/反差感/悬念感
- 具体数字 > 模糊表述（用7不用"多个"）
- 字数控制在 **15~28字**
- 禁用：全面解析、深度解读、浅谈、浅析

### 5类标题必须覆盖

| 类型 | 核心逻辑 | 模板示例 |
|------|----------|----------|
| 痛点共鸣型 | 戳中读者日常困境 | "还在XXX？我用XXX一天搞定" |
| 数字背书型 | 具体数字制造期待 | "X个XXX方法，第N个真绝了" |
| 悬念好奇型 | 信息缺口激发点击 | "关于XXX，90%的人都搞错了" |
| 认知颠覆型 | 挑战常识认知 | "别再XXX了，这才是正确姿势" |
| 共鸣吐槽型 | 引发情绪共鸣转发 | "XXX的痛，只有XX人才懂" |

### 禁用词汇（会导致限流或降低点击率）
- 绝对化：100%、必须、保证、百分百
- 夸大：最全、最好、首选、唯一
- 引流：免费领、扫码加微、私域、立即变现

### 输出格式
```
【爆款标题推荐】
1. [标题] - 类型说明
2. [标题] - 类型说明
...
✨ 首选推荐：[标题] - 理由
```

## 第三步：结构重组

### 核心原则
**绝不按原文顺序改写。** 打散原文所有信息点，按照公众号爆款结构重新编排。

### 强制重组规则
1. **开头必须是钩子**：用场景/问题/争议/数据切入，绝不用"随着...的发展"式铺垫
2. **正文节奏不规整**：段落有长有短，打破等长结构
3. **在25%/50%/75%位置**埋设转发诱因（金句、争议观点、实用技巧）
4. **结尾是行动号召**：引导点赞/评论/转发，而非"综上所述"式总结

### 公众号爆款5段式结构

```
1. 钩子开头（10%）：场景痛点/个人经历/惊人数据 → 3秒抓住读者
2. 核心观点（15%）：一句话概括核心价值 → 给读者继续读的理由
3. 干货展开（50%）：核心方法论/实操步骤/案例分析 → 每300字一个信息亮点
4. 真实感受（15%）：个人使用体验/踩坑经历/行业观察 → 增加可信度
5. 行动号召（10%）：总结金句+引导互动 → 提高完读率和互动率
```

### 结构重组检查
- [ ] 和原文的结构完全不同了吗？
- [ ] 开头是钩子而非背景铺垫吗？
- [ ] 中间有转发诱因埋点吗？
- [ ] 结尾有互动引导吗？

## 第四步：深度改写（核心步骤）

### 角色
一个爱聊天、爱吐槽、爱分享测试/开发经验的真实工程师

### 核心要求
**改写出来的文章，应该像是在跟同事一起吃饭时聊天的内容——口语化、有态度、有故事、有情绪。**

### 强制使用10大改写手法（至少覆盖5种）

参考文档：[de-ai-techniques.md](references/de-ai-techniques.md)

| # | 手法 | 操作说明 |
|---|------|----------|
| 1 | **结构重组** | 打散原文段落和逻辑，按新顺序编排，原文3段的逻辑可变成2段或4段 |
| 2 | **视角转换** | 原文第三人称客观叙述 → 改为第一人称"我发现"、"我测了之后" |
| 3 | **案例替换** | 保留核心观点，原文所有案例替换为自己的场景（带上时间地点等细节） |
| 4 | **上下位迁移** | 抽象概念具体化（如"自动化测试框架"→"Selenium+Pytest这套组合"），或具体工具抽象化 |
| 5 | **信息增量** | 补充原文没有的：实操经验、最新数据、同类对比、常见疑问解答 |
| 6 | **语言风格切换** | 正式→口语、书面长句→短句交替、客观中立→鲜明态度 |
| 7 | **段落节奏打散** | 打破等长段落，制造参差节奏，偶尔插入单句独段 |
| 8 | **幽默个性化** | 注入吐槽、调侃、自嘲、emoji点缀（全文3-5个emoji） |
| 9 | **开头结尾重写** | 开头不用"随着...的发展"，结尾不用"总而言之" |
| 10 | **语气人格化** | 赋予人设：踩过无数坑的老兵、爱折腾的新手、说话犀利的工程师 |

### 去AI味7维检查

改写完成后逐项自检：

| 维度 | 检查项 | 未通过表现 |
|------|--------|------------|
| 情感温度 | 有鲜明的个人态度和情绪吗？ | 四平八稳、正反都说 |
| 口语程度 | 读起来像聊天还是像写报告？ | 书面语、句式工整 |
| 结构自然 | 段落参差不齐吗？ | 每段等长、主题句开头 |
| 人称互动 | 有"你/我/我们"吗？ | 通篇第三人称 |
| 细节真实 | 有具体时间/数字/场景吗？ | 笼统模糊 |
| 用词日常 | 避免AI高频词了吗？ | 赋能、抓手、闭环等 |
| 互动引导 | 有引导转发/评论吗？ | 干净利落结束 |

**AI高频禁用词清单**：赋能、抓手、闭环、痛点、拉通、对齐、倒逼、在当今时代、随着...的发展、不仅...而且...、综上所述、总而言之、值得关注的是、毋庸置疑、显而易见、众所周知

### 聊天风格核心要点

- **短句为主**：单句不超过25字，偶尔夹杂一句长句
- **有态度**：用"说实话"、"其实"、"说白了就是"开头
- **有情绪**：用"炸裂"、"绝了"、"离谱"、"真的香"
- **有场景**：用"上周我在公司试了下..."代替"在项目实践中"
- **有互动**：用"你是不是也遇到过？"、"你猜怎么着？"
- **有留白**：偶尔一句话一段，制造呼吸感

### 写作规范

| 要素 | 要求 |
|------|------|
| 语言风格 | 口语化聊天风，有鲜明个人态度，接地气 |
| 段落节奏 | 2-6句不等长段落，适配手机碎片阅读 |
| 干货密度 | 每300字至少1个可落地信息点或观点 |
| 字数范围 | 1200-2500字（根据内容复杂度自适应） |
| 互动感 | 多用"你"、"我们"、"说实话"拉近距离 |

### 入池条件（必须达标）
- [ ] 标题前8字包含核心关键词

- [ ] 25%/50%/75%位置有转发诱因
- [ ] 结尾有明确的互动引导（点赞/评论/转发）

- [ ] 文中至少1处"金句"适合读者截图转发
- [ ] 至少1处引发共鸣的内容适合点"在看"

### SEO优化
- [ ] 正文每300字自然插入1-2个长尾关键词
- [ ] 标题核心词与正文内容一致（不标题党）
- [ ] 利用微信指数热词优化核心词选择

### 发布时机
- 推荐时段：晚8点（推荐转化率高32%）
- 备选时段：早8点（行业资讯类）
